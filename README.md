# OneClick Resume 

OneClick Resume is a Chrome extension that lets you upload your saved resume to job applications with just one click.

No more searching through Downloads or nested folders every time a website asks for your resume.

## Features

- 📄 Save your resume inside the extension
- ⚡ Upload your saved resume with one click
- 🔍 Automatically detect resume upload fields
- 🌐 Works with dynamically created upload fields
- 🔄 Supports different job application websites
- 🔒 Resume stays locally stored in the browser
- 📁 Supports PDF, DOC, and DOCX resumes

## How It Works

```text
Save Resume
     ↓
Extension stores Resume
     ↓
Open Job Application
     ↓
OneClick Resume detects upload field
     ↓
Click "Use Saved Resume"
     ↓
Resume is attached automatically
